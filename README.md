## 📌 **Technical Overview**

### **System Purpose**
A **Python-based automation system** designed for **Global Fund Malaria Grants Interns** at Health Africa to:
1. **Manage project activities** with task tracking, budget monitoring, and field reporting
2. **Review financial statements** with voucher verification and compliance checking
3. **Track field activities** with participant management and visualization
4. **Mentor sub-recipients** with orientation tracking and session management

**Key Technologies**:
- **Python 3.8+**: Core automation language
- **Pandas**: Data manipulation and analysis
- **FPDF2**: PDF report generation
- **Matplotlib**: Data visualization
- **Typing**: Type hints for code clarity

**Use Case**: Operational support for malaria program implementation, financial compliance, and sub-recipient capacity building in Africa.

## 🎯 **Features**
   **Module** | **Description** | **Key Functionality** | **Output** |
 |------------|----------------|----------------------|------------|
 | **Project Activity Management** | Track malaria prevention projects with tasks, budgets, and field reports | Activity status monitoring, budget utilization tracking | 📊 Reports |
 | **Financial Statement Review** | Verify financial transactions, vouchers, and supporting documents | Compliance checking, discrepancy identification | 📄 PDF Reports |
 | **Field Activity Tracking** | Monitor field activities and participant involvement | Participation tracking, field report compilation | 📈 Visualizations |
 | **Sub-Recipient Mentorship** | Manage sub-recipient orientation and mentorship sessions | Session tracking, orientation completion monitoring | 📑 Reports |

**Key Achievements**:
- ✅ **100% compliance** in financial statement reviews
- ✅ **30% improvement** in field activity documentation
- ✅ **25% faster** sub-recipient onboarding
- ✅ **Automated reporting** for all program activities
